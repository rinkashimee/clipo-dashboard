# Clipo AI Dashboard

A modern SaaS dashboard UI for an AI-powered video clipping platform.

This project showcases a desktop-first dashboard built with React, TypeScript, Vite, and Tailwind CSS. It features reusable components, a scalable folder structure, and mock data to simulate a real-world SaaS application.

## Features

- Dashboard Overview
- Projects Management
- Clip Results
- Analytics
- Templates
- Export History
- Setting Pages
- Subscription Management
- Settings pages
- Reusable UI components
- Mock data implementation

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- clsx
- Phosphor Icons

## Getting Started

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm start
```

Build for production:

```bash
pnpm build
```

Preview the production build:

```bash
pnpm preview
```
